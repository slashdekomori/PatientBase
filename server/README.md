# Запуск сервера
!!! Установочный скрипт расчитан на Linux Debian !!!
!!! Айпи сервера должно быть таким чтобы все клиенты имели к нему доступ !!!

1. Инициализация и зависимости
    Копируем на сервер `setup_server.sh`, `schema.sql`, `setup.ini`
    Заполняем `setup.ini` по примеру внутри
    Запускаем скрипт: `sudo bash setup_server.sh`

# Миграция данных
1. Извлекаем все данные из датабазы:
    Запустить команду (указать путь к датабазе): `python sqlite_to_csv.py путь/к/DataBase.db`
    Появится файл `cases.csv`
2. Залить данные в новую датабазу:
    Перейти на машину где есть доступ к датабазе и установлен пакет `psql`
    Переносим туда `cases.csv` и `load_cases.sql`
    Запускаем команду (нужно поменять айпи сервера): PGSSLMODE=require psql -h АЙПИ_СЕРВЕРА -U pb -d patientbase -f load_cases.sql
